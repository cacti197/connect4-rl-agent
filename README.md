# connect4-rl-agent
This is my own repo to explain the work I did for the connect 4 agent. Basically the entire [notebook](https://colab.research.google.com/drive/1EObVRj4g9vdMKxz2Y8wprC7yCO_lEv2X?usp=sharing) linked is my work heavily guided by [this](https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html) pytorch tutorial. \
In the notebook, I created a simulation step environment for connect 4, which returns step action, state, and reward values. This gets stored into a replay buffer which is used to calculate q values from the Double DQN. The update function uses the lagging q-network to update the policy network so it doesn't update too fast or overtrain. I also implemented the html code so it can have a visual representation in the notebook, along with player input features.\
To credit my partner: My partner helped implement save checkpoints in the notebook. My partner's work included moving the code to vscode and implement better self-play mechanics (saving effective checkpoints and importing a low-depth mini-max to quicken training), along with changing some core implementation decisions like MLP to CNN and board state representation to a 7x7x2 which greatly increased the efficacy of the agent. \
